## Content
All title, introduction, contribution language, four questions, nine report entries, findings, limitations, and citation text come **word for word** from `QandAs_H_POwer(1).docx` (including draft wording, spelling, and capitalization). The link URLs come from the embedded hyperlinks in that DOCX; UTM tracking parameters were removed.

## Source previews
The Tagura & Shuler poster is included as an original PDF and a locally rendered real thumbnail (`assets/poster-original.webp`). Other PDFs remain external links. Their previews are attempted using browser-native first-page PDF display, which some browsers and publisher servers block. **Other report cover images are not bundled** and are not represented by fabricated graphics. To make consistent static thumbnails, the original report PDFs must be downloaded and the first pages rendered to local images.

The HTML and CSS are dependency-free, and the page is readable if PDF previews cannot load. Contact is a plain mailto link.
